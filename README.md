# 🏢 Employee Management System

A comprehensive Employee Management System built with **Spring Boot** and **MySQL**. Features include employee CRUD operations, department management, leave tracking, task assignment, performance reviews, and advanced reporting.

![Spring Boot](https://img.shields.io/badge/Spring%20Boot-3.2.0-brightgreen)
![Java](https://img.shields.io/badge/Java-17-blue)
![MySQL](https://img.shields.io/badge/MySQL-8.0-orange)
![License](https://img.shields.io/badge/License-MIT-green)

## ✨ Features

### 👥 Employee Management
- ✅ Add, Edit, Delete Employees
- ✅ Search employees by name, email, or department
- ✅ Advanced filters (department, salary range, status)
- ✅ Bulk delete employees
- ✅ Employee profile with contact information

### 🏢 Department Management
- ✅ Create and manage departments
- ✅ Assign managers to departments
- ✅ Track department budgets
- ✅ View employee count per department
- ✅ Department-wise statistics

### 🌴 Leave Management
- ✅ Apply for leave (Sick, Vacation, Personal)
- ✅ Leave request approval workflow
- ✅ Track leave balance
- ✅ Manager approval system

### ✅ Task Management
- ✅ Create and assign tasks to employees
- ✅ Set task priorities (High, Medium, Low)
- ✅ Track task status (Pending, In Progress, Completed)
- ✅ Due date tracking

### 📊 Reports & Analytics
- ✅ Employee report generation
- ✅ Department report with budget analysis
- ✅ Salary report with distribution analysis
- ✅ Export reports to CSV/Excel
- ✅ Interactive charts and graphs

### 🔔 Notifications
- ✅ Real-time notifications
- ✅ Email notifications (configurable)
- ✅ Read/unread status tracking

### 🎨 User Interface
- ✅ Modern, responsive design
- ✅ Dark mode support
- ✅ Mobile-friendly layout
- ✅ Real-time clock display

## 🛠️ Technology Stack
